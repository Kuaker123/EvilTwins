PORTAL EVIL TWIN ESP32

Versión: v1.0 | Estado: Activo

⚠️ AVISO LEGAL

Este proyecto se desarrolla exclusivamente con Fines Educativos y para Investigación en Seguridad. Está diseñado para demostrar vulnerabilidades en redes WiFi utilizando la plataforma ESP32. Es una Práctica Académica oficial desarrollada para la carrera de Ingeniería en Ciberseguridad del Tecnológico de Tapachula. Los creadores (Adalid Santos Cruz e IA) no se hacen responsables de ningún uso indebido.

Acerca del Proyecto

Un firmware sofisticado de pruebas de penetración WiFi para el ESP32. Esta herramienta crea un clon (Evil Twin) de una red objetivo y lanza un portal cautivo para evaluar la concienciación en seguridad de los usuarios.

⚡ Características Principales

📡 Escaneo Automático de Redes
🎣 Portal Cautivo (Secuestro DNS)
💾 Registro de Credenciales en SPIFFS
📱 Interfaz de Admin Optimizada para Móviles
🌍 Soporte Global de Canales (1-13)
🛠️ Carga Personalizada de HTML
